# CODERROR

Интерактивное приложение на React, Vite и Tauri: процедурный фон, редактор
музыки Strudel и Архивариус.

## Запуск

```sh
npm install
npm run dev
```

Для запуска настольного приложения через Tauri:

```sh
npm run tauri dev
```

## Сборка

```sh
npm run build
npm run tauri build
```

При первом использовании голос Архивариуса загружает модель Piper и WASM
ресурсы с CDN; без сети остаётся текстовый режим.

## Первая игровая комната

Кнопка «Играть» открывает процедурную Пустоту. Управление: A/D или ←/→ для
ходьбы, Space/W/↑ для прыжка, Esc для возврата в меню. Комната и слои описаны
в `src/rooms/void/index.js`; игровой рантайм и физика находятся в
`src/rooms/RoomRuntime.js` и `src/rooms/VoidGame.jsx`.

Пока это процедурная симуляция: реальные данные диска не читаются. Добавление
источника данных требует отдельной реализации с явным выбором игроком тома,
режимом только для чтения и проверкой поддерживаемой файловой системы.

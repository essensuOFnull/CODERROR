# CODERROR

Интерактивное приложение на React, Vite и Tauri: процедурный фон, редактор
музыки Strudel и Архивариус.

## Запуск

```sh
npm install
npm run dev
```

Для запуска настольного приложения через Tauri:

```sh
npm run tauri dev
```

## Сборка

```sh
npm run build
npm run tauri build
```

При первом использовании голос Архивариуса загружает модель Piper и WASM
ресурсы с CDN; без сети остаётся текстовый режим.

## Первая игровая комната

Кнопка «Играть» определяет NTFS-диск установки и предлагает разрешить чтение
его свободных кластеров. Бэкенд разрешает сканировать только диск установки;
другие тома недоступны. Без успешного сканирования игра не запускается;
отказ возвращает к меню. Управление после запуска: A/D или ←/→ для ходьбы,
Space/W/↑ для прыжка, Esc для возврата в меню. Часть найденного текста образует
цветные символьные пласты ландшафта, остальное дополняет процедурная генерация.
Комната и слои описаны в `src/rooms/void/index.js`; игровой рантайм и физика
находятся в `src/rooms/RoomRuntime.js` и `src/rooms/VoidGame.jsx`.

Сканирование только для чтения: до 64 МиБ данных, буферами по 8 МиБ. Сканер
выбирает до 256 случайных областей карты свободных кластеров вместо
последовательного обхода всего тома; поэтому запуск быстрее, но часть удалённых
данных может не попасть в выборку. Найденные текстовые фрагменты, до четырёх изображений и до двух небольших
видеофрагментов остаются в памяти комнаты. Размер одного изображения ограничен
2 МиБ, видео — 6 МиБ, общий объём медиа — 16 МиБ. Поддерживаются текст UTF-8 /
UTF-16LE, JPEG, PNG, BMP, WebP, AVI, MP4 и WebM. Это поиск по непрерывным
участкам свободного пространства, а не реконструкция фрагментированных файлов:
часть файлов может не восстановиться или оказаться нечитаемой.
Ландшафт имеет случайный рельеф, пещеры и распределение текстовых слоёв;
восстановленные медиа повторно появляются в случайных местах по мере исследования
мира.

Чтение может извлечь личные данные из свободного пространства — перед началом
требуется явное подтверждение. Экспорт и полноценное восстановление файлов пока
не реализованы.

Для доступа к некоторым томам Windows может потребоваться запуск приложения с
правами администратора. Сканирование работающего тома не является форензической
копией: его свободные кластеры могут меняться во время чтения. После TRIM данные
на SSD часто уже физически недоступны. Версия в браузере без Tauri диск не
сканирует.
